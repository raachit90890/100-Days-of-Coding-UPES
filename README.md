# 💻 C Programming — 150 Programs

## 📌 About This Repository

This repository contains **150 C programming solutions**, developed as part of my first-semester B.Tech programming practice.

The collection covers fundamental C programming concepts, starting from basic conditional statements and loops and progressing to arrays, strings, functions, pointers, structures, enumerations, dynamic memory allocation, and file handling.

Each program is written with an emphasis on **simple syntax, understandable logic, and beginner-friendly implementation**.

The repository contains C source code files (`.c`) rather than separate written problem statements.

## 🚀 How to Run the Programs

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

**2. Open the project folder**

```bash
cd YOUR_REPOSITORY
```

**3. Compile any C program**

For example:

```bash
gcc program.c -o program
```

**4. Run the program**

On macOS or Linux:

```bash
./program
```

On Windows:

```bash
program.exe
```

Replace `program.c` with the actual filename. Run the compilation command from the folder containing that file.
